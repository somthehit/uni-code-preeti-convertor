# uni-code-preeti-convertor
## नेपाली अनुवादक, बृहत् शब्दकोश, टाइपिङ मास्टर र टुलकिट (Nepali Unicode & Preeti Toolkit)

पूर्ण रूपमा क्लाइन्ट-साइड र आधुनिक Next.js तथा Tailwind CSS मा निर्मित नेपाली फन्ट रूपान्तरक र भाषिक टुलकिट।

### मुख्य विशेषताहरू (Key Features):
1. **द्वि-दिशात्मक रूपान्तरक (Bidirectional Converter)**:
   - युनिकोड ↔ प्रिती (Unicode ↔ Preeti) तत्काल स्मार्ट रूपान्तरण
   - अङ्क रूपान्तरण (नेपाली / अंग्रेजी / जस्ताको तस्तै)
   - English Lock (अंग्रेजी शब्दलाई स्वचालित रूपमा सुरक्षित राख्ने)
   - लाइभ शब्दकोश टुलटिप (Double-click to inspect dictionary definition)
   - अनुकूलित A4 मुद्रण तथा मार्जिन सेटिङ (Custom Print Margins & PDF Export)
2. **नेपाली डिजिटल बृहत् शब्दकोश (अ देखि ज्ञ सम्म)**:
   - १,२३,०००+ भन्दा बढी आधिकारिक शब्दहरू र अर्थ
   - उखान-टुक्का र वाग्धारा (Proverbs & Idioms)
   - नेपाली हिज्जे तथा हस्व-दीर्घ परीक्षक (Spell Checker with auto-suggestions)
3. **नेपाली टाइपिङ मास्टर प्रो (Typing Master Pro)**:
   - १५ तहको चरणबद्ध पाठ्यक्रम (Home row, Shift keys, Numerals, Conjuncts)
   - वास्तविक हात तथा औँला गाइड (Photorealistic 3D Hand Guide)
   - कमजोर कुञ्जी पहिचान तथा हिटम्याप (Key Accuracy Analytics)
   - शब्दकोशबाट सिधै टाइपिङ अभ्यास पठाउने सुविधा
4. **नेपाली टाइपिङ आर्केड गेमहरू (Typing Arcade Games)**:
   - हिमाली शब्द रक्षा (Typeshala Classic Invaders)
   - फेवाताल बेलुन फोड्ने खेल (Balloon Pop)
   - नेपाल एक्सप्रेस दौड (Speed Highway Race with Nitro)
   - क्रमिक गति वृद्धि (Dynamic Progressive Speed Acceleration) र स्पीड HUD
5. **नेपाली टुलकिट (Toolkit Utilities)**:
   - रोमनाइज्ड नेपाली टाइपिङ
   - बहु-फन्ट रूपान्तरण (Kantipur, Fontasy Himali, PCS, Sagarmatha)
   - अङ्क र अक्षर रूपान्तरक (चेक र बैंक भौचरका लागि)
   - मिति रूपान्तरक (वि.सं. ↔ ई.सं. BS ↔ AD)
   - नेपाली OCR र टेक्स्ट क्लिनर

### सुरु गर्ने तरिका (Getting Started):

```bash
# Dependencies इन्स्टल गर्नुहोस्
npm install

# डेभलपमेन्ट सर्भर सुरु गर्नुहोस्
npm run dev

# प्रोडक्सन बिल्ड
npm run build
npm run start
```
